# Vocalist

A voice-controlled task management application with advanced speech interaction features.

**Course Project:** COMP 6983 - Advanced Interaction Techniques

## Links

- **GitHub Repository:** [https://github.com/Adimvicky/vocalist](https://github.com/Adimvicky/vocalist)
- **Live Demo:** [https://vocalist-aoem-git-main-adim-victors-projects.vercel.app/](https://vocalist-aoem-git-main-adim-victors-projects.vercel.app/)

## About

This project was developed as part of the COMP 6983 - Advanced Interaction Techniques course, exploring voice-based interactions and natural language processing for task management.

## Features

- Voice input for adding and managing tasks
- Wake word detection ("vocalist")
- Continuous listening mode
- OpenAI integration for natural language processing
- MongoDB for task storage

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to use the application.

## Environment Variables

Create a `.env.local` file with:

```
OPENAI_API_KEY=your_key_here
MONGODB_URI=your_mongodb_uri
```
